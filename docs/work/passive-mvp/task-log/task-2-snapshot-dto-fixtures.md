### Key Decisions

- **DTO mirrors the collector projection verbatim** (`tag`, `action`,
  `host`, `remotes`, `dirty`, …) inside the runtime layer; container names
  (`scopedExternals` etc.) are ours. Keeps the Task-7 collector port a
  subset copy. Deliberate omissions (DTO grows per view): per-remote
  `integrity` map (hashes; import-map layer keeps presence only via
  `integrityFor`), `bundle` field, document-map entry lists (counts only).
- **Honest-state semantics:** `runtime: null` iff `nativeFederationGlobals`
  is not available (a global with missing repositories → channel
  `not-recognized`, no partial runtime invented); `importMaps: null` iff
  neither import-map channel yielded data; empty `documentMaps: []` with
  channel `available` is an *observation* (zero maps), not missing
  evidence.
- **Fixtures are TS modules with `satisfies SnapshotV1`**, not JSON —
  compile-time conformance without casts; registry + on-disk completeness
  check closes the "forgot to register" gap. Rejected: JSON +
  `resolveJsonModule` (widened literal types break union checking).
- **Guards live in a separate node vitest run** (`vitest.guards.config.mts`)
  because they scan the repository via `node:fs` — wrong environment and
  wrong ownership for the Angular builder pipeline.
- **Path mapping points at library source**, not `dist/` — `ng serve` and
  tests compile the lib directly; the CLI-generated ng-packagr build target
  stays unused but intact.
- **Source capture checked in** (`captures/`) after Lutz flagged that a
  derive script depending on the private research corpus confuses outside
  readers. Inspected before copying: lab app on 127.0.0.1 (publicly
  deployed at lutzleonhardt.de/frankenstein-meeting-room/, listed on
  native-federation.com/resources), collector-sanitized, no
  cookies/headers/bodies/storage values. README fixes the policy: only
  captures of own lab apps, never real/third-party pages; the privacy
  guard enforces URL/key rules on all checked-in captures (SRI hashes and
  resource-timing keys allowed there). Rejected earlier alternative:
  keep corpus private and label the script maintainer-only.
- **`?fixture=<id>` query param** on the panel/dev URL switches fixtures
  (mirrors Task 1's `?theme=` pattern — plain web input, no `chrome.*`).
- **Boundary-check negative samples are concatenated at runtime**
  (`${'chrome'}.devtools…`) so the guard's own spec file stays clean under
  the tree scan.
